# QA Skill

Try to falsify every material claim.
Check every visual implication.
A PASS is earned, not assumed.
Default publication state is dry-run.

## Mandatory QA Gate 14: Visual Richness & Anti-Black-Void Inspection
Every candidate video must pass an automated visual inspection before QA PASS is granted:
- **No Pitch-Black Backgrounds:** Canvas must have diffuse ambient lighting/radial depth glow and tech grid coordinates. Pure black voids are an immediate FAIL.
- **Illustration Density Check:** Visual stage must contain substantive domain graphics (circuits, network topologies, 3D vector device schematics, particle flows). If a shot consists solely of typographic text boxes or plain geometric outlines without illustrative depth, FAIL gate 14.
- **Visual Contrast & Color Entropy:** Histogram inspection must verify non-zero variance and rich semantic accents (Cyan, Violet, Mint, Amber).

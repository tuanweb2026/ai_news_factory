# Visual Skill

Read `AI_NEWS_VISUAL_STYLE_BIBLE_v1.0.md`.

## Mandatory Visual Directives (Anti-Black-Void Gate):
1. **Never Render Plain Black Void Backgrounds:**
   - Every shot canvas MUST feature a high-tech volumetric radial glow (`radialGradient` with deep cyan `#0E1B2C` or violet `#16132A` diffusing into `#070A0F`), subtle stars/particles, and a coordinate tech grid (`stroke="#141E2C"`).
2. **Mandatory Central Graphic Illustration / System Blueprint:**
   - Text-in-a-box or minimalist wireframes alone are STRICTLY FORBIDDEN.
   - Every single shot must feature a rich, detailed visual illustration occupying at least 40% of the vertical canvas:
     - Neural Cores, 3D vector chips, photon waveguides, or glowing compute pipelines for AI model announcements.
     - Global edge nodes, fiber optic links, and low-latency data clusters for cloud/infrastructure deals.
     - Precision wearable device blueprints, HUD ray-traced visuals, or spatial mesh topologies for hardware/agents.
3. **Use the Approved Shot Vocabulary and Color Semantics:**
   - Cyan (`#4DEBFF`) = Technology / Active Data Flow.
   - Violet (`#9B7CFF`) = AI Intelligence / Cognitive Reasoning.
   - Mint Green (`#54E39A`) = Verification / Optimization / Success.
   - Amber / Coral (`#FF8008` / `#FF5C70`) = Alert / Hardware Thermals / Power.
4. **Never Fabricate Documentary Evidence:** Use conceptual technical schematics with label `CONCEPTUAL VISUALIZATION` or `ORIGINAL VECTOR DIAGRAM`.
5. **Automated Visual Density & Color Audit:** Before finalizing render, the automated QA validator must check image color entropy, ensuring average brightness/contrast and non-black pixel percentage exceeds the visual richness threshold.

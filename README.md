# AI NEWS FACTORY v1.0

A professional multi-agent system for discovering, verifying and producing AI news Shorts.

## Architecture

Orchestrator
→ News Hunter
→ Fact Checker
→ Editorial Storyteller
→ Visual Storyteller
→ QA + Publisher

## Why five agents?

The five roles separate:
- discovery,
- truth verification,
- editorial reasoning,
- visual production,
- quality/publication control.

The Orchestrator coordinates them.

## Antigravity

Google Antigravity 2.0 supports multi-agent orchestration, asynchronous subagents, web research, file operations, MCP integrations and scheduled tasks. This project uses its workspace custom-agent structure under `.agents/agents/`.
